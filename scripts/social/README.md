# Vidéos réseaux sociaux (X / Instagram)

Identités validées le 5 nov. 2026 :
- `statlas` : fond nuit, nom STATLAS et accents dorés.
- `gazette` : fond beige éditorial, « THE GAZETTE », filets rouges.

Format 1080x1350 (4:5), 3 années par seconde, toutes les années affichées, image finale tenue 4 s,
signature « STATLAS RESEARCH ». Chaque rendu produit aussi `*_cover.png` (image finale, pour la vignette).

Lancer depuis GitHub : Actions → « Social video » → Run workflow (fichier, pays, titre, source...).
Le MP4 se télécharge dans les artefacts du run.

Polices : Space Grotesk, Fraunces, IBM Plex (licence SIL OFL). Drapeaux : flag-icons (MIT, voir flags/LICENSE).
